# Forgelands

![Status](https://img.shields.io/badge/Status-On_Hold-orange.svg) ![Language](https://img.shields.io/badge/Language-Java-b07219.svg) ![Modloader](https://img.shields.io/badge/Modloader-Forge-ecaa20.svg)

Forgelands is an experimental crafting mod built on the Minecraft Forge API. Its primary focus is an immersive, GUI-less blacksmithing system that encourages players to interact directly with the game world.

## Core Concept

Inspired by the in-world crafting philosophy of mods like *Create*, the main vision of Forgelands is to replace traditional menu-based crafting with physical, tactile processes:
- **GUI-less Crafting:** Forging gear without clicking through standard inventory menus.
- **In-World Processing:** Mechanics for smelting ores, pouring molten metal into molds, and hammering ingots on an anvil.
- **Dynamic Forging:** A hands-on approach to crafting custom armor and tools.

## Project Status

Forgelands is currently an **early-stage conceptual prototype** and active development is **on hold**. The repository contains the foundational mod infrastructure, basic configurations, and package registries.
